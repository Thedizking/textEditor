# textEditor
Small simple Text editor made using C++ and SDL

Currently only runs on linux

All Code is listed in branch lol

## Required Dependencies

- SDL2 

- SDL_TTF

### Compilation command 

```

g++ main.cpp -o textEditor `pkg-config --cflags --libs sdl2 SDL2_ttf` 

```

#### Usage

```

./textEditor <filename>

```
